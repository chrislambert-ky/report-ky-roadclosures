Project: JavaScript Server-Side Scripting with Node.js

  1. Prepare: The Python ETL downloads and normalizes KYTC source files, then writes the report-ready CSV, Excel, and Parquet datasets.
  2. Transform: The Node.js ETL reads the report-ready CSV, keeps the fields needed for analysis, and deduplicates events.
  3. Enrich: It processes events in batches of up to 100 and calls the KYTC Spatial API to add updated district, county, milepoint, road name, route, and snap information.
  4. Output: Batch progress is written to a temporary file before the completed dataset replaces data/data_v4_final_roadclosures.json. Record counts, API errors, and elapsed time are reported in the console.

Project: HTML/CSS/JavaScript User Interface

  • Responsive Design: All pages are mobile-friendly and use a consistent navigation bar and color scheme.
  • Home (index.html): Dashboard landing page with visual links to all analysis and info pages.
  • Analysis Dashboard: Switch between closure count and total duration by year, month, district, and county. Filter by time and geography, select chart bars to cross-filter, and choose labels, ranking order, and the number of counties shown. District selection limits county results; county selection automatically selects its district.
  • Map View (analysis_by_map.html): Interactive Leaflet map with marker clustering, showing closure locations and popups with details for each closure.
  • Table View (analysis_by_table.html): Tabulator table with filtering, sorting, pagination, and CSV export.
  • About (about.html): Project background, methodology, and documentation for learning and transparency.
