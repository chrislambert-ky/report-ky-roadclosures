# Node.js Spatial Enrichment Workflow

This document describes the Node.js stage of the data refresh for the static [road-closure report](https://chrislambert-ky.github.io/report-ky-roadclosures/). It runs after the Python ETL and is implemented in [`etl_data.js`](../etl_data.js). This is a data-preparation script, not a web server.

---

## Overview

The Python ETL downloads and normalizes annual source files, producing the report-ready CSV. The Node.js ETL reads that local CSV, enriches unique events with current roadway attributes, and writes the JSON consumed by the static website.

---

## ETL Pipeline Steps

### 1. **Read the Python output**
- Reads `data-reportready/kytc-closures-report_dataset.csv`, generated by [`python/etl_pipeline.py`](../python/etl_pipeline.py). Run the Python ETL first.

### 2. **Transform**
- Parses the CSV using `csv-parse/sync`.
- Keeps the event coordinates, comments, report/end timestamps, and duration required for the website.
- Deduplicates records by location, comments, and report timestamp.

### 3. **Enrich**
- Calls the [KYTC Route API](https://kytc-api-v100-lts-qrntk7e3ra-uc.a.run.app/docs) with each event's latitude and longitude to retrieve its district, county, route, road name, milepoint, and snap status.
- Processes up to 100 records concurrently per batch. API failures are preserved on the affected output records as `api_error`.

### 4. **Store**
- Writes batch progress to a temporary file and renames it to `data/data_v4_final_roadclosures.json` when processing completes.
- Reports record counts, API errors, and elapsed time to the console.

## Additional Implementation Details

- **No API Key Required:**
  - The KYTC API is public and does not require registration or authentication.

- **Run the complete data refresh:**
  - From the repository root, run `npm run update-data`. This runs the Python pipeline before `etl_data.js`.
  - See the [web and data workflow guide](../docs/web-and-data-workflow.md) for setup, tests, and dashboard usage.

- **Not Official:**
  - This ETL is a personal/educational project and is not an official KYTC product.
